Sidebar — rudu RepoSidebarItem port

Interactive design spec. Every motion below is justified by frequency, purpose, easing & duration.
Folders: click a folder header (glyph closed→open crossfades through blur) · hover a folder (count→actions swap, rail tints) · drag a workspace into a folder (drop-line shows the landing spot; hover a collapsed folder while dragging → it spring-opens) · New folder drops one in, rename inline.
Rows: hover a header (avatar→chevron, actions stagger in) · hover a row (stats blur out → delete fades in) · click ⇄ (local⇄PR crossfade) · Simulate poll (stats count up + pulse) · toggle slow-mo then re-hover to inspect frame-by-frame.

What you're looking at

  • Header: avatar github.com/{owner}.png + owner/repo; non-GitHub → name + glyph
  • Universal bar, hybrid content — local (mono identity · commit subject · local +N -N) ⇄ PR (author · PR title · PR +N -N)
  • Source flips on PR-open; layout never moves — that's why the flip is a pure opacity+blur crossfade, no reflow
  • Keeps sync · Spotlight · Graphite stack · CI badge · delete-on-hover

🗀 Folders — the grouping tier

  • Three levels: project ▸ folder ▸ workspace. A folder is optional — loose workspaces stay Unfiled, shown below folders (folders are the deliberate, pinned structure).
  • Closed⇄open glyph crossfades through blur(2px) — the same mask the local⇄PR flip uses, so the whole sidebar speaks one motion language.
  • Count ↔ actions swap: the (n) pill fades on hover; rename / new / delete fade in its place — mirrors rudu's stats↔delete swap on rows.
  • Nesting rail: a 2px guide down the folder's left edge tints to the folder colour on hover, so depth reads at a glance.
  • Spring-loaded folders: drag a workspace over a collapsed folder → it auto-opens after 450ms (macOS Finder). Drop to file, drag away to cancel.
  • Drop-line, not a blunt highlight: a precise 2px insertion line shows exactly where the row lands; empty folders show a dashed "Drop a workspace here".
  • Colour as a scan dimension: per-folder --fc tints glyph, count, rail & drop-ring — colour is faster to scan than a name.

⚑ Craft decisions (Emil)

  • Restraint by frequency: a sidebar is opened 100×/day → hovers are opacity-only, ≤150ms, zero bounce. No springs.
  • Never scale(0): delete/flip handles enter from scale(0.9)+opacity.
  • Blur-masks the crossfade: the flip overlaps two text states — filter:blur(3px) blends them into one motion.
  • Custom curves: built-ins too weak → cubic-bezier(.23,1,.32,1).
  • GPU-only: every animation is transform/opacity/filter; grid-rows is the one layout exception (occasional, cheap here).
  • Reduced-motion: movement removed, opacity kept — toggle your OS setting to verify.
  • Hover-gated: all :hover behind @media (hover:hover) so touch taps don't false-fire.
